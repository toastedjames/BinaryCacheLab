# Sample programs

The canonical samples are kept once, under `examples/`:

- `examples/protection/`: protected finite-contract examples, including loops/calls.
- `examples/workflow/sample1.asm`: preserved lookup example.
- `examples/workflow/secret_line.asm`: deliberate secret-dependent control.
- `examples/programs/`: general-program capture examples, including prime generation.
- `examples/benchmarks/`: C source fixtures.

See the root README for setup and launch commands. No historical results are included.
